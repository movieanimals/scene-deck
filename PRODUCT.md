# Scene Deck
<!-- impeccable:product-schema 1 -->
## Platform
Native macOS (SwiftUI).
## Stack
SwiftUI and Foundation, preferred explicitly in the brief. No third-party dependencies.
## Users and purpose
Mac users want quick access to existing Philips Hue Bridge scenes beyond Apple Home's limited surface. Scenes are the primary workflow.
## Capabilities and constraints
Full window, menu bar companion, room/zone grouping, favorites, scene recall, group brightness, and a foundation for live Bridge state. Demo works offline. Pairing and control are explicit user actions. Existing Bridge connection was verified read-only; development writes use mocks. Public GitHub beta authorized. No signing account changes.
## Evidence
The supplied brief is the product authority. Demo rooms and scenes are illustrative, not a real home. Hue v2 reference and TLS guidance returned 403 during research; unverified integration details must remain documented and gated.
## Assumptions
App name Scene Deck and a dark evening-use palette are implementation choices, not claimed user preferences. Existing scenes precede scene creation, editing, gallery imports, or dynamic controls.
